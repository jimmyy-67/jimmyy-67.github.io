# Contributing

## No code contributions

This is a **personal, private project**. I do **not** accept pull requests, code changes, content modifications, or any kind of third-party contribution to this repository.

## Bug reports are welcome

If you find a bug, a broken link, a display issue, or any problem with the site, please **open an issue** describing:

1. What you expected to happen
2. What actually happened
3. Steps to reproduce (browser, device, and screenshots if applicable)

Issues are welcome and will be reviewed. Thank you for helping improve the site.
